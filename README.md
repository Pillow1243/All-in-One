## 🌐 یکپارچه‌سازی با APIهای ۱۰۰٪ رایگان بدون نیاز به کلید (`public-apis/public-apis`)

همه‌کاره پرو از دایرکتوری رسمی [`public-apis/public-apis`](https://github.com/public-apis/public-apis) شامل بیش از ۱۷۸ API عمومی HTTPS بدون نیاز به احراز هویت (در کنار Fallbackهای آفلاین کامل) استفاده می‌کند:
- **ارز، کریپتو و طلا:** Fawazahmed0 Currency API · ExchangeRate-API · CoinGecko
- **هواشناسی و کشاورزی:** Open-Meteo Forecast, Geocoding & Soil/ET₀
- **هوش مصنوعی و ترجمه:** Pollinations Text & Image · MyMemory Translate · Free Dictionary
- **شبکه و امنیت:** Cloudflare DoH DNS · ipwho.is GeoIP · RDAP Whois · HaveIBeenPwned k-Anonymity · is.gd
- **غذا، خودرو و سرگرمی:** TheMealDB · OpenFoodFacts · NHTSA VIN Decoder · Nager.Date Holidays · Hacker News · Official Joke API

## 🛠️ توسعه محلی و بیلد اندروید (Local Development)

```bash
npm install
npm run dev          # اجرای پیش‌نمایش زنده
npm test             # اجرای ۲۶ تست خودکار Vitest (شامل رندر DOM رابط کاربری)
npm run build        # بیلد تولیدی TypeScript + Vite
npm run assets       # بازتولید همه آیکون‌ها/اسپلش‌ها از assets/icon.svg
npx cap sync android # همگام‌سازی پروژه نیتیو اندروید (Capacitor 6)
cd android && ./gradlew assembleRelease
```
