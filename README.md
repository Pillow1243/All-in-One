## نسخه 3.0.0 · ANVIL

**ANVIL** بازطراحی ابزارمحور OmniForge Pro است: پوسته مشکی/زرد با برچسب‌های فنی، خروجی‌های monospace و نشان مهره شش‌ضلعی. نوار وضعیت و نوار پیمایش Android زرد تنظیم شده‌اند. متن رابط خشک و عملیاتی است؛ پیام تبلیغاتی ندارد.

- ۳۲ دسته و ۱٬۰۷۲ ابزار کاتالوگ؛ ۱۲ ابزار کارگاهی به مجموعه افزوده شد.

- نوار وضعیت و نوار پیمایش Android: زرد ایمنی `#FFD400` با آیکون تیره.
- پالت جستجوی سراسری، مسیر مستقیم ابزارها، اشتراک‌گذاری و موتورهای lazy-load حفظ شده‌اند.
- حالت کنتراست بالا، فیلترهای دسترس‌پذیری، کاهش حرکت و انتخاب زبان حفظ شده‌اند.

## دریافت و نصب

1. از [صفحه نسخه 3.0.0](https://github.com/Pillow1243/All-in-One/releases/tag/v3.0.0) فایل `OmniForge-Pro-v3.0.0.apk` را دریافت کنید.
2. نصب از منبع مورد اعتماد را در Android فعال و APK را نصب کنید (حداقل Android 5.1).
3. اگر نسخه پیشین به دلیل تفاوت کلید امضا نصب نمی‌شود، ابتدا نسخه قبلی را حذف کنید؛ قبل از حذف، داده‌های موردنیاز را از ابزار پشتیبان‌گیری صادر کنید.

GitHub Actions برای هر push روی شاخه‌های `main` و `arena/**` تست، وب‌بیلد و Android Release را اجرا و APK و SHA-256 را در Release منتشر می‌کند.

## توسعه محلی

```bash
npm ci
npm run dev          # Vite روی 0.0.0.0:5173
npm test             # Vitest
npm run build        # TypeScript + Vite
npm run assets       # آیکون، splash و Android mipmaps
npx cap sync android # همگام‌سازی Capacitor
cd android && ./gradlew assembleRelease
```

## آزمون‌ها

`npx vitest run` شامل یکپارچگی کاتالوگ، ابزارهای عمومی، محاسبات کارگاهی و تست smoke رابط کاربری است. آزمون‌های فرمول در `src/__tests__/workshopTools.test.ts` نگهداری می‌شوند.
